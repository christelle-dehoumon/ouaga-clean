Explorer la ville

  • Tourner : glisser avec le bouton gauche.
  • Se déplacer : glisser avec le bouton droit (ou deux doigts).
  • Zoomer : molette.
  • Sélectionner : cliquer sur un signalement, un camion, un point de collecte ou un quartier.
  • Vue rue : flèches ou Z Q S D pour marcher, glisser pour regarder, Maj pour aller plus vite.

Bâtiments et routes : OpenStreetMap. Hauteurs des bâtiments estimées, arbres illustratifs. Seuls le secteur pilote et les quartiers téléchargés sont modélisés.
